# Delivery - Bebidas

## Como rodar

Instale o Flutter e o Android Studio 2024.2.1.12 para Windows, indicado pelo professor. Na configuração do Android Studio, instale o Android SDK e o Android Emulator.

No Device Manager do Android Studio, crie um dispositivo virtual e inicie o emulador.

Abra a pasta do projeto no VS Code e rode no terminal:

```cmd
flutter pub get
flutter run
```

Se aparecer uma lista de dispositivos, escolha o emulador. O aplicativo abre direto na tela de bebidas. Toque no botão + para adicionar uma bebida e atualizar o contador da sacola.
